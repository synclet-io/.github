# .github

Default community health files and organization profile for [synclet-io](https://github.com/synclet-io). A repository of the organization that has no file of its own of a given kind uses the one here.

## Contents

| Path | Description |
|---|---|
| `profile/README.md` | Organization profile shown on the [synclet-io GitHub page](https://github.com/synclet-io) |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 2.1 |
| `CONTRIBUTING.md` | How to ask, report and contribute |
| `SECURITY.md` | Private vulnerability reporting and response times |
| `.github/ISSUE_TEMPLATE/` | Default bug report and feature request forms |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |
