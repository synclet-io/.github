# Security Policy

Please do **not** report security vulnerabilities through public issues, discussions or pull requests.

Report them privately through GitHub's private vulnerability reporting in the affected repository: open its **Security** tab and choose **Report a vulnerability**. For the main project that is
**[github.com/synclet-io/synclet/security/advisories/new](https://github.com/synclet-io/synclet/security/advisories/new)**; use it too when you are unsure which repository is affected.

Include the affected version, how it is deployed, steps to reproduce and the impact you expect.

| Step | Target time |
|---|---|
| Acknowledgement of your report | within 3 business days |
| First assessment (confirmed or not, severity) | within 7 days |
| Fix or mitigation for a confirmed critical or high severity issue | within 30 days |
| Fix for medium or low severity | in a following release, usually within 90 days |

We agree on a disclosure date with you and credit you in the published advisory unless you prefer to stay anonymous. Security fixes are made on the latest release.
